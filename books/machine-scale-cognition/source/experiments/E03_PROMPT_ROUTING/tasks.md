Solve all eight items. Return only a JSON object whose keys are `q1` through `q8`. Values must be integers; no units or explanations.

q1. Start x=3. Apply x=(7*x+5) mod 97 exactly 40 times. What is x?

q2. An undirected weighted graph has edges A-B=4, A-C=2, C-B=1, B-D=5, C-D=8, C-E=10, D-E=2. What is the shortest distance from A to E?

q3. How many ways can 4 positions be chosen from positions 1 through 10 if no two chosen positions are adjacent?

q4. Jobs have durations A=3, B=5, C=2, D=4, E=6. B and C require A. D requires B. E requires both C and D. Unlimited workers are available. What is the earliest completion time of E?

q5. A box has 5 red, 3 blue, and 2 green balls. Two are drawn without replacement. What is the numerator of the reduced probability that they have different colors?

q6. Let f(n): if n is even return n/2; otherwise return 3n+1. Starting at 11, apply f exactly 7 times. What value results?

q7. A 3x3 matrix has rows [2,1,0], [1,3,1], [0,2,4]. What is its determinant?

q8. Exactly one of these statements is true: (A) the number is divisible by 2; (B) the number is divisible by 3; (C) the number is greater than 10. Among integers 1 through 15, how many satisfy that condition?
