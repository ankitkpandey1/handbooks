Act as a hostile architecture tester. Seven unnamed operating logics are given below, followed by three frozen expert tasks. Do not harmonize them. Apply each logic literally to each task and allow candidates to fail.

For each P0–P6 × T1–T3, output a compact first-48-hour plan containing: exact first action; machine-scale workload; selector/falsifier specified before that work; maximum object a human reviews; stop/authority boundary; and durable learning captured.

Then score every pair 0–4 on those six properties. Cite the plan feature behind every nonzero score. Penalize boilerplate that could be relabeled as another logic. State whether each P is operationally distinguishable from P0. Identify disqualifying failures, provisional winner and runner-up, and any task where the winner changes. Do not invent outcomes, sources, costs, or measurements.

P0: identify leverage; compile the problem; expand alternatives; select; act; compound.

P1: specify target and sensors; model state; choose intervention; observe error; adapt policy; redesign controller.

P2: find the binding constraint; manufacture machine work around it; manufacture a discriminator; compress the crossing; remove the next constraint; retain the capability.

P3: create options; price information; diversify mechanisms; stage reversible bets; exercise under evidence; reinvest learning.

T3: A university dean asks one analyst to publish a policy for student use of generative AI next semester. Evidence about learning effects is weak and fast-changing; faculty values conflict; enforcement can harm students.
