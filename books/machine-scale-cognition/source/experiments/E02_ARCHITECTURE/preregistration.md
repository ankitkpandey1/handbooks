## H — Selector-first constraint crossing

Locate the binding constraint among representation, coverage, discrimination, review, execution authority, and learning. Specify the selector/falsifier before scaling. Manufacture machine work aimed at crossing that constraint. Emit typed claim/action objects bounded for review. After action, switch to feedback control; under irreversible uncertainty, stage an option rather than force a decision.

## Hypothesis

H will yield more task-specific first actions and stronger selector-before-scale behavior than A0. Pure control will weaken on creative/weak-verifier work; pure portfolio will weaken on deterministic verification; pure market will add ceremony; pure evidence compiler will narrow design; pure bottleneck will omit post-action control unless augmented.

## Measures

Blind-label plans P0–P6. For each task score 0–4: first-action specificity, selector-before-scale, machine-work leverage, bounded review object, authority/stopping boundary, durable learning. Penalize boilerplate operations copied across tasks. Record pairwise operational distinctions and disqualifying failures.

## Interpretation

This is an `ASSESSED_INTERNAL` model probe, not outcome validation. A model preference does not select the book. It can eliminate internally incoherent candidates and generate predictions for later task experiments.
