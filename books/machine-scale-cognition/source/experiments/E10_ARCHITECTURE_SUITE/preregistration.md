# E10 Preregistration — Final Cross-Domain Architecture Suite

**Frozen before execution:** 2026-08-31
**Budget position:** experiment 10 of 10
**Task allocation:** 20 total; 7 SWE (35%); 13 non-SWE
**Conditions:** A0–A5 plus research-derived H; one fresh Luna call per condition; identical tasks/schema; no external research required

## Hypothesis

No pure architecture will dominate. H should improve selector-first behavior and bounded outputs, while evidence compiler should win provenance-heavy tasks, options should win irreversible strategy, control should win monitored operations, and bottleneck logic should win systemic SWE. If outputs collapse to the same generic template, architecture selection has failed.

## Measures

Every task must emit binding constraint, first action, machine-scale work, predeclared selector, bounded human object, stop/authority boundary, and durable learning. Deterministic scoring checks schema and missing fields. Human assessment compares task-specificity, unsupported assumptions, selector strength, review boundedness, and operational distinction. A 50-page guide architecture must route among mechanisms without teaching seven ontologies.

## Failure

- fewer than 7 SWE tasks;
- missing/invalid condition output;
- a claimed winner based only on model self-score;
- H wins merely because its description is longer;
- no architecture loses or no task-dependent winner appears;
- conclusion ignores null/adverse findings from E03–E09.
